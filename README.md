# Logistics Delivery Performance Analysis and Route Optimization

## Project Overview

This project analyzes logistics delivery performance using Python and the DataCo Supply Chain Dataset. It covers data cleaning, exploratory data analysis, predictive modeling, clustering, and route optimization.

## Project Objectives

* Analyze on-time and late delivery performance.
* Identify shipping delays and high-risk delivery groups.
* Build a machine learning model to predict actual shipping duration.
* Apply clustering to identify delivery risk patterns.
* Compare route optimization methods and evaluate distance reduction.

## Weekly Progress

### Week 1: Strategic Planning and Data Exploration

Defined the logistics problem, identified KPIs, explored the dataset, and planned the analytical workflow.

### Week 2: Data Cleaning and Preprocessing

Prepared the data using Python and Pandas, checked data quality, examined outliers, and performed preprocessing.

### Week 3: Advanced Analysis and Visualization

Analyzed delivery status, shipping performance, sales, product prices, category profitability, and correlations using visualizations.

### Week 4: Predictive Modeling and Optimization

Developed a Random Forest regression model, applied K-Means clustering, evaluated delivery risk, and compared route optimization approaches.

## Key Findings

* On-time delivery rate: 45.17%
* Late delivery rate: 54.83%
* Average actual shipping duration: 3.50 days
* Average shipping delay: 0.57 days
* Random Forest regression MAE: 0.989 days
* Route optimization reduced the sample route distance from 28.27 km to 24.73 km, a reduction of approximately 12.52%.
